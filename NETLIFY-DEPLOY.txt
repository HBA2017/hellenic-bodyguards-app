┌──────────────────────────────────────────────────────────────┐
│ ΒΗΜΑ 1: Ανοίξτε το Netlify                                   │
└──────────────────────────────────────────────────────────────┘

1. Ανοίξτε τον browser σας
2. Πηγαίνετε: https://netlify.com
3. Κλικ "Sign up" (πάνω δεξιά)

┌──────────────────────────────────────────────────────────────┐
│ ΒΗΜΑ 2: Δημιουργία Account                                   │
└──────────────────────────────────────────────────────────────┘

Επιλέξτε ΕΝΑ από τα παρακάτω:

□ Email
  - Βάλτε το email σας
  - Βάλτε password
  - Sign up

□ GitHub (Εύκολο)
  - Κλικ "Sign up with GitHub"
  - Authorize Netlify

□ Google
  - Κλικ "Sign up with Google"
  - Επιλέξτε account

┌──────────────────────────────────────────────────────────────┐
│ ΒΗΜΑ 3: Deploy το Site                                       │
└──────────────────────────────────────────────────────────────┘

Μόλις μπείτε στο Netlify:

1. Θα δείτε: "Want to deploy a new site?"
2. Κλικ: "Add new site" → "Deploy manually"
   
   ΟΧΙ "Import from Git" - Επιλέξτε "Deploy manually"!

┌──────────────────────────────────────────────────────────────┐
│ ΒΗΜΑ 4: Upload Αρχείων (DRAG & DROP!)                        │
└──────────────────────────────────────────────────────────────┘

1. Θα δείτε ένα μεγάλο κουτί που λέει:
   "Drag and drop your site output folder here"

2. Ανοίξτε τον File Explorer:
   C:\Users\ikcha\hellenic-bodyguard-app

3. ΣΗΜΑΝΤΙΚΟ: 
   - Επιλέξτε ΟΛΑ τα αρχεία ΜΕΣΑ στον φάκελο
   - ΟΧΙ τον ίδιο τον φάκελο!
   
4. ΣΥΡΕΤΕ τα αρχεία στο κουτί του Netlify

5. Περιμένετε 30-60 δευτερόλεπτα...

┌──────────────────────────────────────────────────────────────┐
│ ΒΗΜΑ 5: Το Site σας είναι LIVE! 🎉                           │
└──────────────────────────────────────────────────────────────┘

Θα δείτε:
✅ "Site is live"
✅ Ένα link: https://random-name-123456.netlify.app
