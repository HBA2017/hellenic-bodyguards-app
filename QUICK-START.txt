Q: Χάθηκαν τα δεδομένα!
A: Κάντε restore από το backup JSON

Q: Πώς αλλάζω κωδικό μέλους;
A: Admin Panel → ✏️ Edit → Αλλαγή password

Q: Πώς απενεργοποιώ μέλος;
A: Admin Panel → ✏️ Edit → Status: Ανενεργό

Q: Μπορώ να βάλω φωτογραφία;
A: Ναι! Βάλτε URL εικόνας ή emoji στο πεδίο Photo

Q: Πόσα μέλη μπορώ να έχω;
A: Χιλιάδες! (localStorage ~5-10MB)
