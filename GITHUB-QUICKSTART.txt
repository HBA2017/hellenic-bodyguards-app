  🚀 ΓΡΗΓΟΡΗ ΕΝΑΡΞΗ: Ανέβασμα στο GitHub Pages
═══════════════════════════════════════════════════════════════════

📌 ΤΙ ΧΡΕΙΑΖΕΣΑΙ:
✅ GitHub account (δωρεάν - φτιάξε το στο github.com)
✅ Τα αρχεία σου (είναι έτοιμα στον φάκελο αυτό)
✅ 5 λεπτά χρόνο

───────────────────────────────────────────────────────────────────
ΒΗΜΑ 1: ΦΤΙΑΞΕ GITHUB ACCOUNT
───────────────────────────────────────────────────────────────────

1. Άνοιξε: https://github.com/signup
2. Βάλε το email σου
3. Διάλεξε password και username
4. Επιβεβαίωσε το email σου
✅ ΕΤΟΙΜΟ!

───────────────────────────────────────────────────────────────────
ΒΗΜΑ 2: ΔΗΜΙΟΥΡΓΙΑ REPOSITORY
───────────────────────────────────────────────────────────────────

1. Στο GitHub, κλικ το "+" (πάνω δεξιά)
2. Διάλεξε "New repository"
3. Γράψε:
   📝 Repository name: hellenic-bodyguards-app
   📝 Description: Digital ID System for HBA Members
   ☑️  Public (ΣΗΜΑΝΤΙΚΟ!)
   ☐  ΜΗΝ βάλεις "Initialize with README"
4. Κλικ "Create repository"
✅ ΕΤΟΙΜΟ!

───────────────────────────────────────────────────────────────────
ΒΗΜΑ 3: ΑΝΕΒΑΣΜΑ ΑΡΧΕΙΩΝ
───────────────────────────────────────────────────────────────────

Θα δεις μια σελίδα με οδηγίες. ΑΓΝΟΗΣΕ ΤΕΣ και κάνε:

1. Κλικ "uploading an existing file"
2. Σύρε ΟΛΑ τα αρχεία από αυτόν τον φάκελο:
   📁 C:\Users\ikcha\hellenic-bodyguard-app\
   
   (Επέλεξε ΟΛΑ με Ctrl+A και σύρε τα στο browser)

3. Περίμενε να ανέβουν (1-2 λεπτά)
4. Κλικ "Commit changes"
✅ ΕΤΟΙΜΟ!

───────────────────────────────────────────────────────────────────
ΒΗΜΑ 4: ΕΝΕΡΓΟΠΟΙΗΣΗ GITHUB PAGES
───────────────────────────────────────────────────────────────────

1. Στο repository σου, κλικ "Settings" (πάνω)
2. Αριστερά, κλικ "Pages"
3. Στο "Branch", διάλεξε: "main" (ή "master")
4. Δίπλα, διάλεξε: "/ (root)"
5. Κλικ "Save"
6. ⏱️  ΠΕΡΙΜΕΝΕ 2-3 ΛΕΠΤΑ
7. Ανανέωσε τη σελίδα (F5)

✅ ΘΑ ΔΕΙΣ ΤΟ URL ΣΟΥ!

───────────────────────────────────────────────────────────────────
🎉 ΕΠΙΤΥΧΙΑ! Η ΕΦΑΡΜΟΓΗ ΣΟΥ ΕΙΝΑΙ LIVE!
───────────────────────────────────────────────────────────────────

Το URL σου θα είναι κάτι σαν:
🔗 https://your-username.github.io/hellenic-bodyguards-app/

───────────────────────────────────────────────────────────────────
📱 ΠΡΩΤΗ ΧΡΗΣΗ
───────────────────────────────────────────────────────────────────

1. ΚΥΡΙΑ ΕΦΑΡΜΟΓΗ:
   🔗 https://your-username.github.io/hellenic-bodyguards-app/
   
   Demo Login:
   👤 Αριθμός: HBA-2024-001
   🔐 Κωδικός: demo123

2. ADMIN PANEL:
   🔗 https://your-username.github.io/hellenic-bodyguards-app/admin.html
   
   Admin Login:
   👤 Username: admin
   🔐 Password: admin123

───────────────────────────────────────────────────────────────────
🔧 ΠΩΣ ΝΑ ΑΛΛΑΞΕΙΣ ΚΑΤΙ ΣΤΗΝ ΕΦΑΡΜΟΓΗ
───────────────────────────────────────────────────────────────────

1. Άλλαξε τα αρχεία στον υπολογιστή σου
2. Στο GitHub repository, κλικ το αρχείο που θες να αλλάξεις
3. Κλικ το μολύβι (Edit)
4. Κάνε copy-paste το νέο περιεχόμενο
5. Κλικ "Commit changes"
6. Η εφαρμογή ενημερώνεται αυτόματα σε 2-3 λεπτά!

───────────────────────────────────────────────────────────────────
⚠️  ΣΗΜΑΝΤΙΚΟ
───────────────────────────────────────────────────────────────────

✅ Τα δεδομένα μελών αποθηκεύονται στο BROWSER (localStorage)
✅ ΔΕΝ αποθηκεύονται στο GitHub
✅ Κάθε συσκευή έχει τα δικά της δεδομένα
✅ Χρησιμοποίησε το Admin Panel για να προσθέσεις μέλη
